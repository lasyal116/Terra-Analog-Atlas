# Sources and third-party components

- NASADEM HGT v001: https://doi.org/10.5067/MEaSUREs/NASADEM/NASADEM_HGT.001. NASA MEaSUREs product, accessed as COGs via Microsoft Planetary Computer. Attribution is not an endorsement.
- LRO LOLA GDR: https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/polar/img/. NASA PDS Geosciences node, Washington University in St. Louis.
- Jezero CTX DEM: https://asc-pds-services.s3.us-west-2.amazonaws.com/mosaic/mars2020_trn/CTX/index.html. NASA/JPL product in the USGS Astrogeology archive.
- Leaflet 1.9.4: https://leafletjs.com/, BSD-2-Clause license in `dist/vendor/leaflet-LICENSE`.
- Natural Earth 1:110m country outlines: https://www.naturalearthdata.com/about/terms-of-use/, public domain. Downloaded from the project's `nvkelso/natural-earth-vector` repository; this is display context, not scientific terrain input.
- Optional OpenStreetMap raster tiles: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright. Do not bulk-download tiles; the explorer requests only visible tiles when enabled.
